# Access Control Policy

## Authentication
All employees must use single sign-on with multi-factor authentication (MFA). Hardware security keys are required for engineers with production access.

## Production access
Access to production systems is granted on a least-privilege basis, requires manager approval, and is time-limited to 8 hours using just-in-time access. All production access is logged.

## Access reviews
User access rights are reviewed quarterly by system owners. Access is revoked within 24 hours of an employee leaving the company.
